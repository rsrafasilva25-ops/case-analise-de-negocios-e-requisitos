# case-analise-de-negocios-e-requisitos
Case prático simulado de Análise de Negócios e Engenharia de Requisitos, contemplando investigação de problemas, levantamento e especificação de requisitos funcionais e não funcionais, regras de negócio, modelagem de processos AS-IS/TO-BE, matriz de rastreabilidade, planejamento de testes e critérios de aceitação.
